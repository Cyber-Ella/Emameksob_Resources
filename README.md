## 📌 Overview

A responsive **printing company website** built with vanilla **HTML, CSS, and JavaScript**.  
It showcases company services, displays project images, and allows users to place orders directly via **WhatsApp integration**.

---

## ✨ Features

- 📱 Fully responsive design (mobile, tablet, desktop)
- 🖼️ Image gallery showcasing printing works
- 🛍️ Services section for offerings
- 💬 WhatsApp order integration (direct chat link)
- ⚡ Lightweight and fast loading
- 🎨 Clean UI/UX design
